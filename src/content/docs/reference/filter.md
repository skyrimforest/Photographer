## 🎞️ 一、什么是「胶片模拟」？

🎞️——富士的“胶片模拟（Film Simulation）”几乎可以说是 **富士灵魂所在**，
它是所有 X 系列相机（包括你的 X-T50）最独特、最迷人的特性之一。
这一功能让你在数码摄影时代，依然能拍出带有“胶片味”的影像。



富士胶片（Fujifilm）在进入数码时代后，
并没有舍弃自己的底片制造传统，而是把过去几十年胶片的成像特性——
例如：色彩倾向、对比度、颗粒感、层次、肤色表现等
——用算法重新“复刻”到数码图像中。

> 💡 胶片模拟 = 数码图像处理算法 × 胶片时代的色彩哲学。

每种胶片模拟模式都代表一种富士历史上的经典底片。
它影响：

* **色彩饱和度**
* **对比与层次**
* **色温与肤色表现**
* **颗粒与阴影走向**

## 🧬 二、胶片模拟的核心原理

从技术上讲，富士的胶片模拟不是滤镜。
它是一套完整的 **色彩科学模型（Color Science Model）**，
在图像生成的各个阶段（色彩矩阵、曲线映射、伽马调整、色彩平衡）中都介入计算。

每种模式都有自己独特的：

* **色调曲线**（决定明暗层次感）
* **色彩矩阵**（决定不同颜色的倾向）
* **伽马与饱和度分布**（决定“通透感”与“胶片感”）

因此：

> 胶片模拟不是“滤镜风格”，而是一种“色彩语言”。

## 🌈 三、富士主要胶片模拟一览（以 X-T50 为例）

| 模拟名称                          | 来源胶片                   | 特点                   | 推荐用途             |
| --------------------------------- | -------------------------- | ---------------------- | -------------------- |
| **Provia / Standard**             | 富士彩色反转片             | 色彩自然、中性平衡     | 通用、风景、人像     |
| **Velvia / Vivid**                | 富士 Velvia 胶片           | 高饱和、高对比、鲜艳   | 风光、花卉、旅行     |
| **Astia / Soft**                  | 富士 Astia 胶片            | 柔和肤色、低对比       | 人像、婚礼           |
| **Classic Chrome**                | 无直接原型（新闻纪实风格） | 低饱和、灰调、怀旧感强 | 纪实、街拍、旅行     |
| **Classic Neg.**                  | 富士 Superia 胶片          | 高对比、影调独特       | 街拍、日常、生活纪实 |
| **Eterna / Eterna Bleach Bypass** | 富士电影胶片               | 平淡灰蓝、低对比       | 视频、叙事摄影       |
| **Pro Neg. Hi / Std**             | 专业人像负片               | 肤色自然，影调柔和     | 商业人像、棚拍       |
| **Acros**                         | 黑白胶片                   | 深邃黑、层次丰富       | 黑白摄影、纪实、建筑 |
| **Sepia**                         | —                          | 棕褐怀旧风格           | 特殊效果、老照片感   |

👉 富士 X-T50 拥有 **最新 X-Processor 5**，支持包括 *Classic Neg.*、*Eterna Bleach Bypass*、*Nostalgic Neg.* 等在内的丰富模式。

## 🧩 五、实用技巧

1. **RAW + JPEG 模式**
   拍摄时保存两种格式：

   * JPEG（应用胶片模拟）
   * RAW（可后期重新切换模拟）
     👉 你可以在后期中自由更换 Film Simulation，而不损失质量。

2. **自定义胶片模拟配方（Recipe）**
   富士用户社群中流行一种玩法——**自定义“配方”**：

   > 在相机中调整色彩曲线、色调、高光、阴影、锐度、颗粒、白平衡偏移等，
   > 并保存为一个自定义配置，创造属于你的“个人胶片风格”。

   📍 参考网站：

   * [Fuji X Weekly](https://fujixweekly.com/)（最著名的胶片配方库）
   * [Fuji Recipes](https://fujirecipes.com/)（社区收集的自定义模拟）

3. **后期中再现胶片模拟**

   * 在 **Lightroom / Capture One** 中导入 RAW 文件后，可以选择富士胶片模拟作为“相机配置文件”。
   * 这样能完全复刻相机内的色彩风格。

## 🌤️ 六、艺术层面的理解

每一种胶片模拟其实代表一种“观看世界的方式”：

* **Velvia** → 感性、热烈、追求视觉冲击
* **Classic Chrome** → 冷静、克制、叙事感强
* **Nostalgic Neg.** → 柔软、温情、如记忆一般
* **Acros** → 剥离色彩，直面光影与结构

> 选择哪一种胶片模拟，其实就是在决定你希望“世界以怎样的颜色被看见”。

## 🧭 七、学习建议

你可以这样练习：

1. 选定一个主题（如“午后街角”）
2. 用不同胶片模拟拍同一场景（如 Provia / Classic Chrome / Nostalgic Neg.）
3. 对比它们的色彩与情绪变化
4. 记录你的感受与选择理由
   → 这将帮助你建立自己的 **“色彩人格”**。
