## 🎞️ 一、什么是 RAW 格式？

**RAW** 是英文 *“raw data”* 的意思，即 **未经相机处理的原始影像数据**。
当你按下快门时，感光元件（传感器）会捕获大量的光信号，而 RAW 文件就是对这些信号的**完整记录**。

相比之下，**JPEG** 是相机在拍摄后对图像进行了自动处理（包括降噪、锐化、压缩、白平衡、色彩调整等）后生成的成品照片。

可以简单理解为：

| 格式     | 类比             | 说明                                   |
| -------- | ---------------- | -------------------------------------- |
| **RAW**  | 相机拍下的“底片” | 未经过相机处理，保留最多的光与色彩信息 |
| **JPEG** | 已冲洗好的“照片” | 相机自动调整后的最终输出，可直接分享   |

---

## 📊 二、RAW 文件的核心特点

1. **高动态范围（High Dynamic Range）**
   RAW 文件能保留比 JPEG 更多的明暗信息。
   👉 例如在阴影区域和高光区域，你可以在后期中“挽救”那些在 JPEG 中已经纯黑或纯白的细节。

2. **更高的色深（Color Depth）**
   JPEG 通常是 8-bit（每个颜色通道 256 个层次），
   RAW 通常是 12-bit 或 14-bit（4096 或 16384 个层次）。
   → 这意味着后期调整色彩时，**不会出现明显的色阶断裂或噪点增加**。

3. **灵活的白平衡调整**
   RAW 文件中白平衡只是“记录信息”，你可以在后期中任意更改色温，而不会损失图像质量。

4. **更高的后期自由度**
   曝光、对比、色彩、锐度、降噪都可以非破坏性调整，
   你能更好地“还原记忆中的光”，而不是被相机算法限制。

---

## ⚖️ 三、RAW vs JPEG 对比

| 项目       | RAW                   | JPEG                |
| ---------- | --------------------- | ------------------- |
| 动态范围   | 宽（可修复过曝/欠曝） | 窄（容易死白/死黑） |
| 色彩层次   | 丰富（12-14 bit）     | 有限（8 bit）       |
| 文件体积   | 大（20~50MB）         | 小（3~10MB）        |
| 处理速度   | 拍摄慢，需后期        | 拍摄快，可直接用    |
| 后期自由度 | 极高                  | 低                  |
| 适合人群   | 专业/创作摄影         | 记录/快拍用户       |

👉 简言之：

* **拍 RAW 是为了“最大控制权”**
* **拍 JPEG 是为了“方便与速度”**

## 📷 四、富士 X-T50 的 RAW 特点

富士的 RAW 文件扩展名是 **`.RAF`**（Fuji RAW Format）。
它包含了：

* Bayer 或 X-Trans 传感器数据（取决于型号）
* 拍摄时的胶片模拟信息（仅用于参考）
* 相机参数、镜头校正信息、白平衡数据

富士的特别之处是：

> 富士相机的 JPEG 引擎极强，胶片模拟（Film Simulation）可以在机内生成非常优秀的 JPEG。
> 因此很多富士用户采用 **RAW+JPEG** 模式——既保留“可修”的 RAW，又有“可直接分享”的成片。

---

## 🧑‍💻 五、RAW 文件的后期处理

常用软件有：

* **Adobe Lightroom / Camera Raw**
* **Capture One (for Fuji)** → 专门针对富士 X-Trans 传感器优化，效果非常好
* **DxO PhotoLab**
* **富士官方 RAW File Converter EX（免费）**

后期可做的主要调整包括：

* 曝光、对比度、阴影与高光
* 白平衡（色温、色调）
* 曲线与色彩分级（Color Grading）
* 镜头校正与锐化
* 胶片风格模拟或 LUT 应用

---

## 🪄 六、实战建议

1. **拍摄设置**

   * 模式：RAW+JPEG（同时保存两者）
   * 白平衡：AUTO（后期可调）
   * 胶片模拟：选择你喜欢的（如 Classic Chrome / Provia），方便预览效果

2. **存储建议**
   RAW 文件较大，建议使用高速 SD 卡（UHS-II 及以上），
   并定期备份（推荐 Lightroom 自动导入备份功能）。

3. **后期建议**
   RAW 并非要“修得完美”，
   而是要**重新表达当时你所感受到的光与色**。
   调整不应只是技术操作，更是审美表达。

---

## ✨ 七、小结

| RAW 是给摄影师的第二次机会。                     |
| ------------------------------------------------ |
| 它让你在后期中重新雕刻光影、重塑色彩、重构情绪。 |

用好 RAW，不是为了修得“更亮、更清”，
而是为了让画面更接近 **你眼中那一刻的温度与呼吸。**
