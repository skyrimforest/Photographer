## 🎓 阶段二：构图与视觉语言（建议 2–3 周）

### 🎯 学习目标

1. 掌握构图的核心规律与视觉引导逻辑

## 🧠 一、摄影的视觉语言核心

### 1️⃣ 构图是画面的“语法”

构图的本质是——

> 你在一张二维平面上，如何安排视觉元素，使观者的眼睛沿着你希望的路径移动。

常见构图法不是死规则，而是“引导观者视线”的工具。

| 构图法      | 视觉特征           | 情绪/效果     | 实战技巧    |
| -------- | -------------- | --------- | ------- |
| **三分法**  | 主体位于画面1/3交点    | 平衡、稳重、自然  | 人像、风景通用 |
| **对称构图** | 左右或上下对称        | 稳定、秩序、仪式感 | 建筑、倒影   |
| **引导线**  | 道路、栏杆、光影线条引导视线 | 动感、方向性    | 街头、建筑   |
| **框中框**  | 用窗户、门框、树叶包围主体  | 层次、空间深度   | 风景、人像   |
| **留白**   | 主体小、背景空        | 孤独、宁静、极简  | 极简主义场景  |
| **对角线**  | 视觉沿对角线延伸       | 张力、力量感    | 动态场景、街拍 |

📸 **练习方法**：
找一个普通场景（如公园、街口），用三分法、对称法、引导线法分别拍一张，体会画面“重心变化”。

---

### 2️⃣ 画面的“节奏与平衡”

* **视觉平衡** ≠ 完全对称
  亮色、鲜艳、清晰的区域“视觉重量”更重。
  → 例如，一张画面中，暗处一盏亮灯能“平衡”空旷背景。
* **节奏感**
  重复的元素（窗户、灯、行人）形成视觉节奏，如音乐中的拍子。
* **动静对比**
  一静一动的元素（静止的人 + 流动的车灯），让画面有“时间感”。

📷 **练习**：
拍摄“秩序与打破秩序”：
整齐排列的物体中，加入一个突出的元素。

---

### 3️⃣ 层次与空间：让二维画面“有深度”

| 技法           | 作用          | 示例           |
| ------------ | ----------- | ------------ |
| **前景-主体-背景** | 增强空间立体感     | 树枝 → 人物 → 建筑 |
| **光影分层**     | 用光的对比形成远近感  | 日落时逆光街头      |
| **焦点控制**     | 用浅景深突出主体    | f/2.0 拍人像    |
| **透视变化**     | 仰拍/俯拍制造空间冲击 | 建筑、街头        |

📷 **练习**：
选一个固定地点（比如咖啡店），尝试三次拍摄：

* 从窗外拍（前景窗框）
* 从中景拍（人物为主体）
* 从内景拍（背景为街道）
  再对比层次感差异。

## 🎨 二、构图的心理与情绪表达

| 视觉方向      | 潜在心理感受   | 应用场景      |
| --------- | -------- | --------- |
| **左→右**   | 前进、顺畅、积极 | 动作延伸、旅途   |
| **右→左**   | 回溯、反思、压抑 | 纪实、回忆     |
| **下→上**   | 崇高、力量    | 建筑、仰拍     |
| **上→下**   | 弱小、悲伤    | 低角度看人     |
| **中心构图**  | 稳定、仪式感   | 人物特写、纪实主体 |
| **斜线与倾斜** | 不安、动感    | 动态街拍、摇摄   |

> 💡 拍照前问自己：“我想让人感到什么？”
> 构图就像语气，决定观众的情绪体验。

## 🏋️ 三、实践计划（建议 2 周）

| 周次      | 主题      | 内容与练习                                  |
| ------- | ------- | -------------------------------------- |
| **第1周** | 构图实验周   | 每天选择一种构图法（对称、三分、引导线等），在生活中找到适合的场景，拍3张。 |
| **第2周** | 视觉节奏与空间 | 尝试“层次感”与“前景-主体-背景”练习，每天拍一个小系列。         |

📌 额外挑战：
选择同一主题（如“地铁”），连续拍5天，每天用不同构图表达“拥挤”“秩序”“孤独”“流动”“等待”五种情绪。

## 🧩 四、视觉感知训练

### 1️⃣ 观察练习（不拍照也能提升）

* 每天随机看一个场景，想象如果拍下来，**主体是谁**、**要切掉什么**、**从哪个角度拍**。
* 看别人的照片，先不看说明，问自己：“这张图吸引我的是什么？为什么？”

### 2️⃣ 模仿与再创作

* 找喜欢的摄影师作品（如 Alex Webb、森山大道、荒木经惟），试着在生活中寻找类似构图与光线。
* 不用复制场景，而是复现“节奏与感受”。

## 🧩 六、阶段作业与思考

📷 **任务：**

1. 选择一个主题（例：“城市的边缘”、“光的流动”、“孤独的午后”）
2. 用 5 张照片讲述这个主题（不同构图、角度）
3. 写一句话说明每张图的情绪意图

🎯 **评估标准：**

* 主体是否明确
* 构图是否服务于主题
* 画面是否有层次与引导
* 是否让观者感受到“意图”
