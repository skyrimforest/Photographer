## 🎨 阶段四：色彩与审美养成（提升作品气质）

> 学习目标：
>
> * 理解色彩背后的心理与叙事作用
> * 能够通过配色、光线与色温控制画面气质
> * 找到自己的“色彩签名”风格
> * 提升作品的“高级感”与“个人气质表达力”

---

### 🧭 一、课程导向

摄影的色彩并非只是“颜色”，而是 **情绪、时间、记忆与意图的具象化表达**。
这一阶段，我们要学会：

* 看到颜色的“关系”，而不是单个颜色
* 用色彩讲述情绪、表达故事
* 逐步建立属于你自己的“视觉语言”

---

### 📚 二、学习模块详解

#### **模块1：色彩基础与心理学**

* **色彩属性三要素**：色相、明度、饱和度（Hue / Value / Saturation）
* **色彩关系**：互补色、类似色、单色调、冷暖对比
* **色彩心理学**：

  * 蓝色 → 平静、理性
  * 红色 → 激情、危险
  * 绿色 → 生命、和平
  * 黄色 → 活力、警示
  * 紫色 → 神秘、高贵
* **练习**：

  * 每周拍摄一个“色彩主题”（如“蓝调星期一”、“午后橙光”）。
  * 用 Lightroom/HDR 编辑尝试不同色温、饱和度下的情绪变化。

---

#### **模块2：光线与色彩的融合**

* 理解“光线色温”（Kelvin 值）：

  * 清晨日光 5500K → 纯白冷调
  * 傍晚阳光 3500K → 金色暖调
  * 阴天光 7000K → 蓝灰冷调
* **富士胶片模拟与色温配合技巧**：

  * Classic Chrome（复古冷色）
  * Astia Soft（柔和自然）
  * Velvia（高饱和自然）
  * Pro Neg Hi / Std（人像肤色优化）
* **练习**：

  * 同一场景用不同胶片模拟+白平衡拍摄，分析气质变化。
  * 模仿摄影师作品（例如森山大道的高对比黑白，或小林纪晴的低饱和暖色人文）。

---

#### **模块3：配色与构图的交织**

* **主色 / 辅色 / 点缀色** 概念
* **色块构图法**（color blocking）
* **留白与色彩平衡**：用空间衬托颜色的主导性
* **练习**：

  * 用三种主色（蓝、黄、红）拍摄不同主题
  * 拍摄一组单色作品（例如只用“蓝色”讲故事）
  * 模仿电影截图构图（例如《花样年华》的红绿对比）

---

#### **模块4：风格识别与色彩签名**

* **建立风格参考库**：

  * 从 Pinterest / Behance / Flickr 收藏喜欢的调色风格
  * 用 Lightroom 建立个人色调模板库
* **形成“个人签名”色调**：

  * 反复使用一个偏好的配色逻辑（冷暖反差、低饱和暖调、暗黑风格等）
  * 让人一眼看出是你拍的
* **练习**：

  * 用你自己的 preset 拍摄 3 个主题（城市、人像、夜景）
  * 建立你专属的“摄影风格调色板”

### 💡 额外建议

* 定期“重拍”同一主题，观察色彩语言的成长
* 试着让朋友或我来点评你的色彩逻辑，而不仅是构图
* 可开始为作品命名（用情绪词或颜色词，比如“薄荷下午”、“雾蓝街角”）
  ——这会帮助你建立审美语言
