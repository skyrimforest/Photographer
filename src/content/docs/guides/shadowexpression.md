## 🎓 阶段三：光影与色彩美学（建议 3–4 周）

### 🎯 学习目标

1. 理解光的性质、方向、色温及其对情绪的影响

---

## 🧠 一、光影的语言：摄影的“句法”

> 摄影的本质是“用光写画”—— *photo-graphy*。
> 所以理解光，是从“拍照”进入“创作”的关键分水岭。

---

### 1️⃣ 光的种类与情绪

| 光线类型           | 特征       | 情绪氛围       | 典型场景      |
| -------------- | -------- | ---------- | --------- |
| **柔光**（阴天、窗光）  | 阴影淡、色彩柔和 | 安静、温柔、日常感  | 室内、肖像     |
| **硬光**（晴天直射）   | 阴影强烈、对比高 | 冲突、力量、戏剧性  | 午后街头、建筑   |
| **逆光**（光在主体后方） | 光晕、轮廓亮   | 梦幻、浪漫、神秘   | 黄昏人像      |
| **侧光**         | 立体感强     | 稳定、质感、情绪张力 | 静物、纪实     |
| **顶光**         | 阴影集中     | 冷漠、孤立      | 中午建筑、戏剧照明 |
| **底光**         | 从下打光     | 不安、超现实     | 创作摄影      |

📷 **练习建议**：
每天选择一个时间段（早晨 / 正午 / 黄昏 / 夜晚），用相同场景拍摄。
对比光线变化下的“气氛转变”。

---

### 2️⃣ 光的方向与立体感

| 光位      | 表现效果     | 拍摄提示      |
| ------- | -------- | --------- |
| **前光**  | 细节清晰但平淡  | 拍记录性照片    |
| **侧光**  | 体积感、立体   | 拍人像、纹理    |
| **逆光**  | 光晕、剪影、氛围 | 拍情绪感场景    |
| **顶光**  | 对比强烈、戏剧性 | 拍建筑、舞台感   |
| **反射光** | 柔化对比     | 使用白墙、地面反光 |

> 💡 富士相机的 EVF（电子取景器）能实时预览光线效果，非常适合光影练习。

## 🌈 二、色彩的心理与叙事

### 1️⃣ 摄影中的色彩三要素

* **色相（Hue）**：红、绿、蓝、黄等基本色调
* **饱和度（Saturation）**：色彩强度，决定“活泼或沉稳”
* **明度（Brightness）**：亮或暗，决定情绪基调

### 2️⃣ 色彩心理学速查表

| 色彩     | 情绪印象      | 富士胶片模拟推荐              |
| ------ | --------- | --------------------- |
| **红**  | 热情、危险、力量  | Velvia                |
| **橙**  | 温暖、亲切     | Classic Chrome、Eterna |
| **黄**  | 活力、希望     | Provia                |
| **绿**  | 平静、生命力    | Astia                 |
| **蓝**  | 冷静、孤独、思考  | Classic Chrome、Acros  |
| **紫**  | 神秘、浪漫     | Eterna                |
| **黑白** | 纯粹、纪实、时间感 | Acros（黑白模拟）           |

📷 **练习任务：**
每周选择一种主色调（例如“蓝”或“橙”），围绕它拍一个系列作品。
可以用富士的 **胶片模拟 + WB 微调** 控制色彩气氛。

---

### 3️⃣ 色彩搭配与对比

常见的几种视觉效果：

| 搭配类型              | 视觉感受  | 说明                |
| ----------------- | ----- | ----------------- |
| **互补色**（蓝-橙、红-绿）  | 冲突、张力 | 富有戏剧性             |
| **邻近色**（黄-橙-红）    | 协调、温暖 | 视觉舒适              |
| **单色系**（灰蓝、浅蓝、深蓝） | 极简、统一 | 电影感强              |
| **低饱和配色**         | 纪实感   | Classic Chrome 风格 |

> 🎨 建议多参考 **Eterna** 与 **Classic Chrome**，富士色彩体系非常擅长低饱和电影质感。

## 🎥 三、光影与色彩的叙事力

摄影不只是“记录”，而是“表达”。
你可以用光线讲故事，比如：

| 情绪 | 光线特征   | 色彩倾向   | 典型构图    |
| -- | ------ | ------ | ------- |
| 宁静 | 柔光、低对比 | 暖色、低饱和 | 中心或对称   |
| 孤独 | 冷色、强对比 | 蓝灰     | 留白构图    |
| 希望 | 逆光、暖色  | 黄橙调    | 引导线向光源  |
| 压抑 | 顶光、暗部多 | 黑灰、低明度 | 居中或封闭空间 |

> 💬 练习思维转变：
> 以前拍“看起来好看”的照片，现在要拍“有感觉”的照片。
> 想清楚“这张图要让人感受到什么”，再决定光与色。

## 🏋️ 四、实践训练计划（建议 3–4 周）

| 周次      | 主题   | 练习内容                                 |
| ------- | ---- | ------------------------------------ |
| **第1周** | 光线观察 | 记录一天中光线变化（早/午/晚/夜），拍相同物体的光影差异。       |
| **第2周** | 光影创作 | 拍摄逆光、侧光、剪影、反射光四类作品各3张。               |
| **第3周** | 色彩叙事 | 选择1种主色调（蓝 / 橙 / 灰 / 绿），拍一个小系列表达某种情绪。 |
| **第4周** | 综合表达 | 主题创作：《光的故事》—— 用5张图讲一个时间变化或心情变化。      |

## 🧩 五、工具与技巧建议

* 使用 **直方图 + 高光警告** 控制光线细节
* 拍 **RAW+JPEG**，在 Lightroom 中尝试微调色温、饱和度、曲线
* 学会使用 **白平衡偏移**（WB Shift）让画面更冷/暖（例如偏 B+2 R–3 → 冷蓝感）
* 富士 **胶片模拟 + DR 模式**（Dynamic Range 200/400）能保留更多高光细节

## 💬 七、阶段作业

> 📷 主题作业：《光与色的故事》

要求：

* 拍摄一组 5–8 张作品
* 每张都围绕某一类光线（如柔光 / 逆光）或色调（冷 / 暖）
* 整体要能看出情绪连贯性（如“黎明到黄昏”、“孤独的蓝”）

评估要点：

1. 光影是否传达了明确的气氛
2. 色彩是否统一且有意图
3. 整体叙事是否完整（视觉连贯）
4. 拍摄是否自然流畅（技术不喧宾夺主）
