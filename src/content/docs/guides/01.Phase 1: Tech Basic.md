## 🧠 一、理论核心：摄影语言的基础逻辑

### 1️⃣ 曝光三角：控制画面的“亮度与质感”

| 参数                      | 控制内容     | 画面效果                                     | 举例说明                        |
| ----------------------- | -------- | ---------------------------------------- | --------------------------- |
| **光圈（Aperture）**        | 控制进光量与景深 | 大光圈（f/1.4–f/2.8）→背景虚化；小光圈（f/8–f/16）→整体清晰 | 拍人像：f/2.0 背景柔和；拍风景：f/11 全清晰 |
| **快门速度（Shutter Speed）** | 控制曝光时间   | 快（1/1000s）凝固动作；慢（1/10s）表现运动轨迹            | 慢门拍水流、车轨                    |
| **ISO**                 | 感光度      | 提高亮度但增加噪点                                | 夜景 ISO 提高至 1600–3200 仍可用    |

> 💡 富士的拨轮设计特别适合练习“手动意识”——多去动这些拨轮，理解每个变化带来的画面差异。

---

### 2️⃣ 曝光补偿与测光模式

* **曝光补偿（+/- 拨轮）**：快速调整亮度（+ 让画面更亮，- 让画面更暗）。
* **测光模式**：

  * **多区测光**（默认） → 综合整幅亮度；
  * **点测光** → 只看一个小点的亮度；
  * **中央重点测光** → 以中心为主。
    实战建议：在逆光场景中用 **点测光**，能保留人物细节。

---

### 3️⃣ 对焦与白平衡

* **对焦模式**：

  * **AF-S（单次对焦）**：适合静态物体
  * **AF-C（连续对焦）**：适合移动物体
  * **MF（手动对焦）**：精确控制焦点（配合放大功能）
* **白平衡（White Balance）**：影响整体色温感受

  * 晴天偏暖，阴天偏冷；
  * 你可以大胆尝试“错误的白平衡”——冷色拍夕阳、暖色拍阴天，有意制造情绪差。

---

### 4️⃣ 富士的胶片模拟（Film Simulation）

富士相机的灵魂。每种模式都是对经典胶片的数字再现：

| 模式                  | 风格特征        | 适合场景     |
| ------------------- | ----------- | -------- |
| **Provia/Standard** | 中性自然，色彩平衡   | 日常拍摄     |
| **Velvia/Vivid**    | 高饱和、对比强烈    | 风光、花卉    |
| **Astia/Soft**      | 柔和肤色，细腻色彩   | 人像       |
| **Classic Chrome**  | 减饱和、低对比，纪实感 | 街拍、城市    |
| **Eterna**          | 柔和、电影感      | 视频、纪实风格  |
| **Acros**           | 黑白胶片风       | 建筑、光影、纪实 |

> 📷 练习建议：拍同一场景，用 3 种胶片模拟拍摄，体会“情绪变化”。

## 🏋️ 二、实践计划（建议 7 天）

| 天数        | 主题      | 内容与练习                                        |
| --------- | ------- | -------------------------------------------- |
| **Day 1** | 相机熟悉    | 研究拨轮、菜单、对焦模式；试拍 20 张不同曝光的照片，观察差异。            |
| **Day 2** | 光圈练习    | 拍摄静物与人像，用不同光圈（f/2 → f/8）比较背景虚化。              |
| **Day 3** | 快门练习    | 拍车流、人走动、水流，用 1/1000s、1/30s、1/5s 各拍一张，感受动态模糊。 |
| **Day 4** | ISO 与测光 | 同一场景下改变 ISO（200→3200），体会噪点变化；尝试点测光与多区测光。     |
| **Day 5** | 胶片模拟    | 选择 3 种 Film Simulation，拍同一场景；记录情绪变化。         |
| **Day 6** | 综合练习    | 手动模式（M档）练习：自由控制曝光三角，理解相互平衡。                  |
| **Day 7** | 外拍作业    | 外出拍摄 10 张照片，总结：哪种胶片模拟 + 曝光设置最符合你的喜好。         |

## 🧩 三、进阶小技巧

* 使用 **直方图（Histogram）** 观察曝光是否均衡，不要过曝或死黑。
* 拍摄 RAW 格式（或 RAW+JPEG），方便后期调整色彩。
* 开启 **高光警告** 功能（画面亮区闪烁提示），帮助判断是否曝光过度。
* 富士的 **Q 菜单**（快速菜单）可自定义 Film Simulation、白平衡、动态范围等常用参数。
